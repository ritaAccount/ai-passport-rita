LUCKY TRIPLE SLOT

玩家开玩手册 · 三键 · 三轴 · 纯娱乐虚拟分（不是真钱）

01 你要干嘛

花 Credits 开转，撞组合拿倍率。累计赢分升级，解锁更大 Bet，冲 JACKPOT / MEGA / BONUS。

  • 每次进游戏：500 Credits
  • 等级 / 累计赢分 / 下注档会保存；Credits 重进会重置
  • 长期玩的是右上角 Lv 和 Need，不是本局余额

02 按键

口诀：单击做事 · 双击切换 · 长按重开

主页

操作效果
上/下 单击翻立绘；翻完换主题（JIE / P3 / MARI）
上/下 双击音量 + / −
OK 单击进入局内
OK 双击BGM 开/关
OK 长按重置 Credits + 等级进度（慎用）

局内

操作效果
OK 单击开转（扣 Bet）
OK 双击CONFIG 焦点：Bet → Vol → BGM
上/下 单击调节当前焦点项
上 双击回主页

转轴/横幅播放中按键无效，等动画结束再按。

03 界面

区域看什么
左上Credits / Bet（或中奖提示）

底部 CONFIG左 Bet·BGM，右 Vol；> = 当前选中

05 结算与倍率

  1. 扣 Bet → 按档次抽结果 → 滚轴停下
  2. 中奖：Credits += Bet × 倍率
  3. Bonus×3：先播小页，再开高价值池
  4. 破等级门槛：琥珀色 LV N! 横幅

06 保底 & 小贴士

档大概规则
银约连续 10 次不中 → 小奖保底
金/钻/大师另有高奖、特殊奖保底
大师约 30 次无 Jackpot/Mega → 大奖保底
  • 先用 Bet 10 听懂横幅声音，再加注
  • 拧设置前先 OK 双击，确认 > 指着谁
  • Credits 不够就降 Bet；想重开人生就 OK 长按
